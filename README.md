# Fast Quiz — Frontend

Vue 3 + TypeScript + Vite + Pinia + Tailwind CSS. Ayrıntılar için `docs/PROJECT.md`.

## Yerel kurulum
```
cp .env.example .env
npm install
npm run dev
```
Backend'in `http://localhost:8000` adresinde çalışıyor olması gerekir (`..\FastQuizBackend`).

## Komutlar
```
npm run test
npm run lint
npm run type-check
npm run build
npm run gen:api     # openapi/schema.yml → src/types/api.d.ts
```
